# 冠塔戦記（ブラウザ版）

塔を奪い、霊脈を断ち、マスターを討つ。将を直接動かす 1 対 1 のリアルタイム対戦（対 CPU）。

**遊ぶ：https://yuruge.github.io/kanto-senki-web/**

- Godot 4.7.2 で作ったゲームを Web に書き出したもの（このリポジトリには書き出したファイルだけを置いている）。
- PC のブラウザ（Chrome・Edge）推奨。キーボードとマウスで遊ぶ。スマホのタッチ操作はまだない。
- 操作：WASD 移動／Shift ダッシュ／同じ方向キー 2 回でステップ／Space ジャンプ／J・左クリック 射撃／K・右クリック 格闘／L ロック切り替え／1・2・3 兵／F ついてこい／Z・X・C 召喚獣／Esc 一時停止
- フォント：Noto Sans CJK JP（SIL Open Font License 1.1）
